# 界面实现与验证

v2 主导航为互动、人物、研究、设置。浅灰白底、中文 16px 正文，少量头像颜色区分人物。移除了场景卡片墙、舞台光效、持续闪烁和日常对话里的技术面板。

采用官方 Radix shadcn `Sidebar`、`Resizable`、`Message`、`Bubble`、`MessageScroller`、`Marker`、`Tabs`、`Sheet` 和表单组件。新增组件通过 CLI 安装并检查 imports；已有 Button 的暗色渐变改为语义色。

房间围绕实际博弈组织：信任场景顶部显示关系双方、投资与返还、承诺履约和实际补偿；心理侧栏显示人物自己报告的事件评价、情绪、需要、猜测、策略及变化来源。心理与实际行动分别呈现，研究页可并排比较。公开视角不显示私人状态。移动端人物列表和心理详情共用一个 Sheet。原始工具参数仍可展开，完整配置和事件在研究页查看。

心理“变化”页展示每次状态的情绪、策略变化和主观信任前后值，配对到下一次状态更新之前的本人实际发言与行动。可点击“查看当时心理”固定查看某次状态，再返回最新状态；回看不会修改人物或对局。`scripts/ui-psychology.mjs` 验证历史状态与当前状态正确切换、证据展开、主题、手机布局和无浏览器异常，使用明确的离线夹具。

`scripts/ui-v2.mjs` 启动内存数据库和离线真人房间，在真实浏览器中测试发言、消息展示、点击特定人物、单层移动 Sheet、横向溢出及浏览器异常。输出截图位于 `data/v2-ui`。这是功能和布局验证，截图中的对话由测试真人输入，不是模型效果评估。
