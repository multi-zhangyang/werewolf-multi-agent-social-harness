# 重构验收对照

> 历史记录：本表对应早期 runtime v2 与 apodex 配置，不是当前生产 Agent 的验收规范。当前模型固定为 gpt-6-luna、256000 配置上下文、原生 Responses；以 [当前 Agent 设计](agent-design.md) 和 [原生 Responses 验证](validation-native-responses.md) 为准。下文保留当时的实际状态。

本表区分实现、运行正确性与行为效果。代码通过检查不代表自然度、人物辨识度或心理真实性已经得到验证。

| 计划要求 | 实现与证据 | 验收状态 |
| --- | --- | --- |
| 独立 Agent、收件箱、会话、目标和记忆 | runtime/participant.ts、run.ts；真实 SDK 离线请求检查不同人物的历史不会混用 | 已验证 |
| 世界事实、合法机会、确定性结算与人物决策分离 | ScenarioAdapter；经济博弈规则、6–12 人狼人杀及特殊角色规则测试 | 已验证 |
| 就绪队列、点名优先、私聊并行、每人一个循环 | 队列顺序、无话后结束、私聊并行、发送者未结束时接收者唤醒测试 | 已验证 |
| 直接自然语言接话，无必经心理/承诺协议 | SDK 普通回复直接提交；没有 prepare_message、心理评分或承诺编号 | 已实现；语言质量另评 |
| 跨频道主动联系、沉默、检索与记笔记 | 通用工具与合法联系人；发送成功交出机会，wait 无占位发言 | 机械行为已验证 |
| 工具失败原循环反馈，不修 JSON、不补行动 | SDK 工具错误回传；重复行动、缺失行动、循环耗尽和迟到结果测试 | 已验证 |
| 未完成输出不进入历史 | 提供商完成状态在工具执行前检查；length/content_filter 离线响应测试 | 已验证 |
| 经历来源和私有状态隔离 | 本人可见事件生成经历；笔记校验来源；服务端视角裁剪和快照详情授权测试 | 已验证 |
| 连续世界、独立实验、不可变快照、中文检索 | SQLite、FTS5 trigram、世界唯一写锁；实验不回写与快照隔离测试 | 已验证 |
| v2 API、真人行动、暂停/恢复、只读回放 | API 鉴权、重复提交、取消和重启回放测试；不恢复在途模型调用 | 已验证 |
| 三场景入口、浅色 shadcn 互动页、人物与研究页 | Sidebar、Resizable、Message/Bubble/Scroller、Tabs、Sheet、表单；桌面和手机浏览器检查 | 已实现，待用户审美反馈 |
| 模型接入与思考强度 | Cardinalize apodex-1.1-mini；交流 low、必需行动 medium，实际请求参数测试 | 已配置并实际调用 |
| 回放不调用模型、旧档案只读、单一运行内核 | v1 执行和心理回写代码移除；旧创建/删除入口禁用 | 已实现 |
| 每场景 5 组新旧体验样本 | study 生成匿名对话和独立配对密钥；所有失败保留 | 15 组文件已有；旧信任博弈 1 份无发言，只有 14 组双方有内容 |
| 固定模型/快照/种子、关系记忆与发言机制消融 | study --ablate；2×2 条件、每组 2 次；保存源码、配置、逐局指标与样本差异 | 属初步采样，不能推断显著因果效应 |
| 人工盲评自然度、重复、人物辨识与关系连续性 | blind-review.html 可填写并导出真实评分 | 尚未进行，不能宣称已通过 |
| 关系经历影响回应、行动及信任修复 | 机制和采样工具已经具备，真实模型仍可能重复、误算、选择沉默或耗尽预算 | 研究效果尚未验收 |

实际批次、完成率、版本差别和已知问题见 [验证记录](validation-v2.md)。远端 Windows/Linux、Node 22/24 CI 配置已经添加，但只完成了本机 Windows / Node 24 的执行。
