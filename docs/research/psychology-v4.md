# 心理状态驱动的信任博弈

2026-10-03。根据用户反馈，将重点从人物展示和一般聊天转向：遭遇背叛后，不同人物如何评价事件、形成情绪与猜测，并作出有代价的回应。保留原有未提交重构和数据。

## 可以操作的闭环

1. 投资前，受托者自主承诺返还到账资源的 0–100%。承诺不强制执行。
2. 投资、到账、实际返还按世界规则执行。系统仅核对金额，不替人物判断是否应当原谅。
3. 每次决策前，同一人物的模型先更新私有主观状态：事件评价、情绪、需要、信任、意图猜测、替代解释、下一步预测及策略。
4. 成功保存的状态进入实际决策调用。心理评价调用不能发消息或操作资金，实际行动由随后独立的决策循环提交。
5. 结算后受托者可以从自己累计所得中拿出补偿。道歉不移动资源，补偿真实扣款；选择 0 同样合法。
6. 角色轮换后继续观察。完成局的心理状态进入人物快照，连续互动可继承。

`experiment.psychology=off` 提供关闭心理评价的对照；`trustProtocol=classic` 保留经典规则。人格消融和关系记忆设置仍可使用。旧的 `study:personality` 明确关闭新增心理流程，以保留其“附加人格上下文”诊断定义。

## 边界与失败处理

主观状态是模型生成的模拟变量，未经生物或心理测量校准。它不是模型隐藏推理的原文，也不是另一个人物真实的内心。没有硬编码“背叛必须愤怒”“公平人格必须合作”或默认投资金额。

`update_mind` 的可用证据和关系对象来自本次可见集合，工具参数使用枚举，服务端继续检查来源与权限。每次机会最多保存一次。非法参数只能在两步心理调用预算内由模型自行纠正；未保存状态便不进入决策调用。对尚未提交状态的输出截断，以相同参数最多重试一次；首次错误和响应计数保留。除此之外不追加语义重试，更不重放已提交的交易。

状态、来源和时序记录在私有 note 事件中；其他 Agent 和公开观众无法访问。研究视角经原有权限校验后展示。关闭关系记忆阻止跨局状态继承，同局心理状态仍保留；若需要彻底消融心理状态，应使用 `psychology=off`。

## 界面围绕过程组织

首页可选择关系双方并直接启动两轮实验，也可进入自定义规则、人物与消融条件。房间展示真实资源流转、公开承诺、实际返还和补偿；选择人物后查看其当前情绪、需要、关系猜测和私下策略。“变化”页显示情绪、策略变化和主观信任前后值，将每次状态更新与之后的本人实际发言和行动并列，且不会跨过下一次状态更新强行关联。点击记录可固定查看当时完整状态和证据，再返回当前状态，不修改对局。

研究页增加“心理与决策”并排比较。角色与研究视角继续区别；公开界面不会得到私有状态。界面沿用官方 shadcn 的 Message、Bubble、Item、Collapsible、Tabs、Card、Progress、Select、Field 等，保持黑白与深浅模式。Progress 的实际值同时传递给无障碍属性。

## 作为研究工具仍需解决的问题

当前能够记录“经历 → 主观评价 → 实际决定 → 新经历”的闭环；这不等于已经复现人的心理。后续优先级应当由可检验的问题决定：

1. **先校准事实理解。** 单独标注当前角色、可用动作、实际到账与收益计算的错误；把错误和有证据的策略性隐瞒区分开。不能用“情绪化”解释所有错算。
2. **固定经历，再改变人格。** 同局人物的角色和收件内容可能不同；直接比较两个人不能识别人格效应。重复使用同一初始状态与事件材料，并平衡角色、名字和出场顺序，再做人格及心理机制消融。世界 seed 不保证外部模型输出可重复。
3. **把道歉和补偿拆成分支比较。** 目前 6 次诊断按固定顺序观察，只能说明该路径上的变化。严格比较应从同一个背叛后的快照分别进入无回应、道歉、不同金额补偿条件，避免将顺序或累积信息当成补偿效应。
4. **以实际行为为主要结果。** 记录下一次投资、返还比例、真实补偿成本与合作维持轮数。自报的情绪、信任和策略作为待校准的中间变量，不能代替行为指标或人类心理量表。

自由对局不会被系统强制导向背叛；若双方最终守约，该样本同样保留。要稳定观察背叛后的差异，应使用控制刺激的诊断，再用自由对局检查这些差异能否在互动中维持。
