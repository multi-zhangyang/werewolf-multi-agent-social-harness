# 混合心理机制与独立修复实验

本版将程序维护的事实和状态连续性，与模型自主的事件解释、表达和交易选择连接起来。模拟心理变量未经人类或生理测量校准；研究结论须来自实际行为与对照。

本轮已结束：受控分支87/90完成，自由局5/6完成；固定配置确认29/32首次无错误、32/32最终完成。实现、全部失败、行为差值与真实耗时见[最终结果报告](v5-results.md)。

## 已接入的机制

- `ActorObservation` 直接来自经济规则：参与者、当前角色、阶段、到账对象、实际资金与合法行动。收到的说法、世界事实和自身旧观点分区输入。
- `hybrid-v1` 在每次决策前保存正式状态。模型提出目标情绪，程序先按游戏阶段衰减旧情绪，再按默认 0.6 / 0.4 合并；同一来源不重复累计。需要、关系观点与情绪分别处理，关系不会因时间流逝自动重置。
- 合作意愿和履约能力分别估计；保留竞争解释、目标冲突和调节方式。没有规定背叛后必须生气、报复或原谅。
- `update_mind` 返回归约后的状态，决策使用同一份返回值。程序惯性和全部心理模块均能消融；研究界面可以调整惯性与阶段衰减。
- 未来事件由规则引擎给出合法对象、轮次和阈值，模型选择 `eventId` 并估计概率。存储时展开为完整预测；只对后来实际发生且可判定的事件计算 Brier 分数，零到账的比例预测不评分。

技术依据：[Hindsight 的记忆语义划分](https://github.com/vectorize-io/hindsight)、[ETI 的意愿与能力推断](https://aclanthology.org/2026.acl-long.77/)、[评价与表达分离](https://aclanthology.org/2026.cas-1.7/)。本版没有安装 Hindsight 服务、微调模型或复制多候选预演。证据限制见 [Exa 调研](exa-frontier-2026-10-03.md)。

## 可复测的输入与故障

每次实际模型请求保存研究者可见的 `DecisionCase`：完整 SDK 输入、工具 schema、模型设置、前态、响应/异常、耗时与源码哈希。认证信息与环境中的密钥被脱敏。原始记录不暴露给其他 Agent 或公开观众。

复测直接调用模型，不使用工具执行器；返回的交易调用只作为数据保留。丢弃不可序列化的旧请求信号及 SDK 跟踪上下文，并使用 NoopTrace，禁止复测向外部追踪服务发送记录。已提交行动不会重放。

心理、交流与行动分别支持思考强度和输出预算。HTTP client 不作隐藏重试；尚未提交的截断、连接/超时、429、5xx 或提供商路由错误最多原参数重试一次，所有尝试仍保留。结构和语义校验错误在已有工具循环预算内返回模型纠正。若心理调用两轮纠正后仍未提交正式状态，则允许一次相同参数、干净上下文的重试，避免无效 JSON 在纠正历史里反复出现；已保存心理或已提交行动不重放。

## 受控分支的定义

第一轮通过现有规则执行：承诺返还一半、投资 6、实际返还 0。背叛后的共同状态只生成一次，不增加公开自述；从该状态独立重建三个分支：没有回应、相同道歉而补偿 0、相同道歉且真实补偿 9。初始背叛是实验设置，不声称自然发生。

第二轮角色交换，模型自主承诺、返还、补偿；第三轮自主投资。固定策略伙伴第二轮投资 6，第三轮返还到账一半，其他补偿为 0。除第一轮修复回应外，受控后续讨论阶段不插入新增对话。选择通过规则引擎真实结算；原对局、其他分支与连续世界 heads 均不修改。

人格实验只改变宜人性 0.2 / 0.8。名字、价值、目标、表达习惯和其余维度保持一致。完整心理、关闭惯性、关闭全部心理三组，各有三个修复条件，每格重复五次，共 90 条分支。前缀使用不含条件名称的随机 ID，避免向模型泄漏实验标签；共享前缀的调用用量单独记录。

补偿同时改变资源和社会信号，不能把组间差异解释为纯粹的心理安慰效应。低返还本身不证明报复。报告包含全部失败、实际行为分布、配对差值与描述性 bootstrap 区间；不根据结果删除样本，不把重复预测当作独立人类观察。

## 界面与 API

首页有自由博弈与受控实验入口。`#/studies` 提供实验配置、进度、分支、行为图表、全部样本与导出；`#/research/:id` 增加决策案例查看及隔离复测。房间可由实际行动/履约事件定位人物随后首次心理及对应表达和行动。

使用官方 shadcn 的 MessageScroller、Message、Bubble、Marker、Card、Tabs、Sheet、Collapsible、Field、Slider、Table 和 Chart，支持黑白深浅主题与手机布局。三个修复条件按面对补偿、自己返还、再次投资三个时点对齐解释与关系修订。行为分布图显示每条有效分支的取值，可切换返还、补偿、投资和收益；表格列出原始值、区间及高低宜人性差值。旧版单值信任按原样显示，不推造新的关系维度。

- `POST/GET /api/v2/studies`，`GET /api/v2/studies/:id`：创建和查看批次。
- `POST /api/v2/studies/:id/stop`，`GET /api/v2/studies/:id/export`：停止、导出。
- `GET /api/v2/studies/:id/trials/:trialId`：完整分支记录。
- `GET /api/v2/studies/:id/diagnostics`：只读重新检查原始响应，包含提供商漏报的截断与不完整参数；不修改档案。
- `GET /api/v2/studies/:id/trials/:trialId/decision-cases`：该分支及其共同前段的案例索引，排除其他分支。
- `GET /api/v2/runs/:id/decision-cases`：案例列表。
- `GET /api/v2/decision-cases/:id`，`POST /api/v2/decision-cases/:id/replay`：案例与无交易副作用的复测。

批次要求管理者权限，普通对局案例允许该局房主或管理者；参与者令牌不能读取完整研究案例。隔离复测可选择原配置或单独调整输出预算与 low / medium，保存实际发送的配置与原案例版本。SQLite 使用增量表，不修改旧档案。服务重启保留已完成结果并标记中断，不自动继续付费调用。

## 完整结果审计

`node --import tsx scripts/hybrid-audit.ts --database=data/society-v5-verified.sqlite --output=data/v5-verified-audit` 只读打开 SQLite，导出原始分支、案例索引、行为分布及描述性区间，并重放所有合法行动核对角色和账本。它还重新计算心理归约，检查后续请求中使用的正式状态，以及各修复分支的共同前缀。审计不请求模型，也不回写原局。

预测比较先按人物与目标事件取最后一次有效预测，再以分支平均 Brier 汇总，避免同一事件的反复预测虚增样本数。策略修订统计声明的策略类别变化，不能据此断言产生了报复动机。正式分支与自由局的完成数、耗时和失败原因，以实际完成的审计导出为准。

导出包含原始 JSON、逐分支 CSV、人格差值、修复条件差值和机制消融差值。效应量使用原单位的均值差，区间采用固定分析种子的描述性 bootstrap；小样本、失败缺失和多重比较限制解释。`scripts/plot-hybrid.py` 生成可独立保存的 PNG / SVG / PDF；未完成批次必须显式选择诊断模式，并带有未完成标识。

## 固定批次与后续修正的版本边界

上述固定批次均在独立进程中使用其登记的源码版本完成收集，没有热更新决策代码或补写失败样本。运行期间发现的工具约束修正在工作区单独实现：待提交领域行动时，`wait` 返回可纠正的错误，而不是结束机会；受控沙箱的手写笔记现在能够被后续上下文与检索读取，并验证来源、区分主观观点与事实。两条分支的笔记保持隔离。

因此固定批次中的等待失败仍计为失败。最终审计确认原受控批次的 `remember` / `recall_memory` 调用均为0，笔记修正未影响其实际轨迹。修正后错误路径的验证见独立复测及回归测试记录。

修正后的六场自由局中，`c726b444` 因连续四次 `recall_memory` 均为空而耗尽 `maxTurns=4`，仍计为失败。旧检索将多个空格分隔的中文关键词当作一个完整短语。当前工作区改为逐词匹配并按命中词数排序，继续限制人物、可见分支和相关对象，保留记忆的事实／主观类型与来源。只读原局、在内存副本中比较原查询：四次中的三次从零命中变为有可见来源的结果，另一次仍为空；没有请求模型，也没有据此声称这局能够完成。诊断见 `data/v5-memory-diagnostic.json`，对应源码 `e5eb6cc6d64da8af10438631770fc252f6dfe0aea38e5635402e04a2455cfcd5`。真实完成率仍属于先前冻结的配置与检索实现；该检索修正通过离线回归，尚未另跑六场验证。

运行入口：`npm run study:hybrid -- --kind=calibration --output=新目录`；`--kind=repair --repeats=5` 为 90 条分支，`--kind=free` 为六场三轮自由局。固定配置确认使用 `scripts/hybrid-confirm.ts`。指定模型始终为 Cardinalize 的 `apodex/apodex-1.1-mini:free`。
