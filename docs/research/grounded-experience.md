# 有具体行动和结算依据的经历记忆

## 从真实记录发现的问题

v6 的原生执行与适用性检查已经工作，但不能由此推断学习内容可靠。继续检查固定 v5 来源后发现：自动经历只保存“策略 protect 后获得 2 分”之类的关联摘要，没有具体动作参数、场景和实际结算内容；模型还会为同一结算另外写一条个人记录。提炼输入把这些记录并列为“经历”，界面也用记录条数表示“几段经历”。

来源 `93496278-4838-46bb-aab0-a0cbd4423d14` 的真实四轮质量均为低，第一轮报告高、其余三轮报告低。builtin-01 的一条策略却写成“四次低质且报告均准确、一次高质报告失实”。其五条来源记录实际只引用四次结算：第一轮被自动记账和个人笔记分别引用。事实次数与笔记条数的混用是需要修正的输入问题；这项观察尚不能证明它是模型错误的唯一原因。

对两个预定来源的四个人物复盘输入作只读检查，原记录数分别为 5、6、4、5，实际结算均为 4。检查保留原始质量与报告字段，未改写旧策略、旧快照或失败。证据为 `data/grounded-memory-prototype-1791073016112/preflight-real-source.json`；这是零模型调用的真实输入预检。

## v7 的实现

1. 生产动作通过原生 SDK 校验后，其具体参数进入暂存的私有决策。只有完整激活提交后，后续结算才可以引用这些动作。
2. 自动经历保留原结算文本、轮次、场景、本人实际动作参数和实际回报，标记 `origin=ledger`；人物写入的解释标记 `origin=agent`。旧记录没有来源标记时保持未知，不自动升级为事实。
3. `experienceEvidence` 以原始结算 ID 分组。一条结算可以关联多条记录，但 `distinctOutcomeCount` 只计唯一结算，`recordCount` 另计笔记。结算的结构化事实与人物记录分开提供，质量真值与公开报告继续分开。
4. 分组只使用本次本人可见的来源。旧场景不会被标成当前场景；没有历史场景信息时保持未知。实际动作只关联同局、同结算反馈，发言不进入实质动作列表。
5. 新提炼策略保存 `sourceOutcomeIds`，同时保留原 `sourceMemories`。界面分开显示结算次数和记录条数，旧记录只称为来源记录。复盘输入改为按结算分组，记忆与原账本不被去重删除。

检验、采用、反馈、来源保护与原子提交仍由同一个生产 Agent 和官方 Agents SDK 完成。没有增加模型执行循环、额外专家 Agent 或隐式重试。模型可以拒绝不适用的策略，也可能作出错误解释；正确的证据呈现不是可靠推理的证明。

## 研究依据与范围

- [Cognitive Architectures for Language Agents](https://arxiv.org/html/2309.02427v3) 区分工作记忆、经历、语义与程序性知识，以及内部记忆动作和外部行动。本次采用的是经历记录与解释的区分，不把分类本身当成学习有效的证据。
- [Transfer Learning through Analogy in Games](https://ojs.aaai.org/aimagazine/index.php/aimagazine/article/view/2332) 讨论源与目标在关系词汇不同的情况下如何作结构对应。当前实现保留实际行动与结果，让模型比较谁知道什么、谁承担后果、哪些行为可核验；没有声称实现该文的 SME、minimal ascension 或 metamapping 算法。
- [Recursive Contemplation](https://aclanthology.org/2024.findings-acl.591/) 和 [K-Level Reasoning](https://aclanthology.org/2025.naacl-long.370/) 区分推断他人状态与推断他人如何看待自己。这指出通用社会推理还需要更明确的高阶信念建模。当前对手假设、私有意图和经验机制不等于已经完整实现这些方法。

## 验证要求

确定性检查复现五条记录对应四次结算，核对真假报告字段、原记录不变、实际动作参数保留、同一结算不重复计数、私有事件与旧身份隔离、历史场景不误标。SDK 回归确认参数来自正式调用，收益由后续账本写入。

真实验证继续采用原定 v5 来源快照，运行信任和公共品两个新目标。保留原先协议、明确检验和策略采用门槛，另核对实际 HTTP 中的结算分组、原始事实、每条新经历及其已提交动作参数。拒绝不算正迁移，来源原文与之前批次的失败结论保持不变。真实结果以[验证记录](../validation-native-responses.md)为准。
