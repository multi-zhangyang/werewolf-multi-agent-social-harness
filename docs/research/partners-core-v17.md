# 合伙人 v17 核心诊断与验收

## 已定位的问题

v13 的背叛与末轮情境最终提交行动，但分别发生 6 次和 5 次错误，并各重试一次。实际请求暴露了四类问题：候选动作没有完整类型；准备后重新填写动作和预测，改变预登记内容；后续调用仍带准备前的心理与上下文；模型混淆字符串 JSON、心理分组及 `plan.plan` 嵌套。

v17 直接声明稀疏心理、平面计划和分阶段候选动作。准备后的提交只接受候选编号、最新上下文、发言和意图，原样继承动作、预测与表达目的。每次模型调用刷新正式状态；原始参数在 SDK 校验前按调用编号保留，错误提供具体字段路径。过期、外来候选和附加字段均不产生资金或心理交易。

修复没有替模型选合作、填金额或修补残缺 JSON。计划版本、私有投影、预测登记和世界守恒继续由规则检查。`record-only` 先固定行动，再在隔离会话中记录评价。

## v17 重复验收设计

入口为 `npm run study:partners:validation`，每次使用独立数据库和冻结源码。当前批次目录为 `data/partners-validation-1791048323767/`，harness 为 `partners-sdk-v17-stage-contract`，源码摘要为 `d2b4ae434b4044fb1a8c87b4dee4b64cdf85307853a510d8413924c5ae533de1`。

运行前预登记：四个固定情境各重复三次，至少 11 / 12 单次决策提交；六场全新双 AI 三轮游戏至少五场结束；合作意愿 0.2 / 0.8 × 完整机制 / 只记录心理各重复三次，12 / 12 提交且后置评价无失败。最多两个自主任务并行，固定决策与游戏有整体时限。种子控制初始世界，不控制提供商采样。

固定情境前史标为规则引擎设置，只统计当前一次模型决策。游戏不含脚本人类或预先执行的行动。合法退出与跑完轮次分别统计；失败、重试、截断与缺失保留。案例核对冻结版本与候选凭证，全部世界检查守恒，干预源局逐字不变。最终统计以同目录 `results.json` 为准。

## 剩余模型问题

本批种子 5 在世界版本 9 失败。首尝试把退出候选放错位置，把字段名写成候选数组元素；两次工具校验均拒绝。随后响应信封非法，清空暂存状态重试一次；第二次耗尽 12000 输出 token 而截断。原局停在已提交检查点，没有补写第十次行动。失败案例 `3077ab94-8c93-48d4-8d05-6591e1ed8d6a` 的副本在 `data/partners-v17-delivery-1791048614139/failed-5db84016-77c7-449f-9ba8-f6cbef29e1a5.json`。

其他错误包括漏候选编号、心理或计划字段放错分组、已有计划再次 `create`、非退出候选漏预测、预测行动与指标不匹配。动态 schema 已提供约束，模型仍可能不遵守。不能通过接纳非法 JSON 或替模型挑动作提高完成率。

干预批次还发生一例独立心理记录截断：模型输出工具对象后附加非法尾部及大量空白，耗尽预算。该动作已由隔离的行动会话固定并提交，后置评价失败单独保留，不得称作成功心理记录。严格的“后置评价零失败”门槛因此尚未达到。

## 构建与界面修复

`parse5` / `entities` 从对话共用包拆出，原 509.20 kB 分块变为 352.73 kB 对话包和 156.08 kB HTML 解析包；最大 JavaScript 分块约 409 kB，体积警告消失。解析包未进入首页依赖。修改改善分块结构，不代表整个对话页总下载体积大幅降低。对比在 `data/partners-v17-delivery-1791048614139/build-report.json`。

完整玩家流程还发现，结束后的自动跟随偶尔把早期历史滚回屏幕外。现在活跃对局跟随新输出，暂停、失败和结束时释放跟随；恢复时仅原本位于底部才继续。使用 AI Elements 现有滚动 API，不增加逐帧循环。

协议修复通过 34 文件 / 230 项离线测试、lint、类型和生产构建。界面通过三轮人机夹具、六分支夹具、失败回滚、多尺寸回看、增量 SDK 夹具、对手隔离、失败部分输出、历史心理和手机/深浅主题检查。夹具只验证工程行为，真实模型表现来自独立数据库。

## 解释边界

90 条真实修复分支尚未作为新内核通过证据；心理与人格因果效应尚未建立。成功提交也可能有错误信念、算术或角色叙述。补偿同时改变资源与社会信号；低返还和收入声明差异不单独证明报复或欺骗。所有版本的失败与来源分别保留，不合并成单版本成功率。
