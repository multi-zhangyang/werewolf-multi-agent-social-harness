# Exa 调研：让心理状态成为可验证的博弈机制

调研日期：2026-10-03。根据用户要求，本次及后续资料检索改用 Exa；Agent 模型仍为 Cardinalize 的 `apodex/apodex-1.1-mini:free`。本次完成文献和实现调研、保存检索凭据与资料，没有把下面的研究建议标成已经实现或验证的功能。

## 对当前项目的判断

当前 `appraisal-v2` 已实现先保存主观状态、再作实际决定，并能在界面上对照心理与行为。这是有用的实验基础，但心理字段是否对行为有独立贡献、是否稳定呈现人格差异，仍缺少实证。上一轮完整对局在第 2 轮连续截断；字段合法和离线测试通过，也不能说明 Agent 已经理解了角色、交易和他人意图。

这次检索带来四项具体修正：

1. 将“已经收到款项”等世界事实和“我猜对方会给钱”等主观信念分别表示和评估。当前自然语言心理状态中存在把尚未执行的投资当成事实的错误。
2. 将对手的合作意愿与能力分开判断；同样的损失，可能来自欺骗、失误或资源不足。单个信任值无法充分区分这些情况。
3. 用投资、返还、补偿、核查成本和行为预测评估心理机制；情绪叙述和自报分数作为待验证的中间变量。
4. 优先做小规模、固定情境的输入与预算实验，再运行长局。截断和昂贵的重复调用需要单独诊断，不能直接推定都是“思考不够”。

## 核对的一手研究与可借鉴的机制

### 1. 人格引导：要测行为，并允许结果依赖模型

[Effects of personality steering on cooperative behavior in large language model agents](https://www.nature.com/articles/s41598-026-56163-8)，Scientific Reports，2026-06-02。

论文在重复囚徒困境中比较基线、人格提示和单维度人格操控。在所测试的三个模型中，宜人性对合作的影响最强；其他维度影响较小，合作提升还可能增加被利用的风险。作者将人格引导描述为行为偏置，而非确定性的行为控制。

**对项目的用法：** 固定名字、目标、角色、经历与模型，只改变一个人格维度，观察实际选择的分布。现有 `full / persona-only` 主要检验附加人格上下文，不能替代逐维度操控；也不应把某人格每次都作同一选择当成成功标准。论文未测试 Apodex，方向必须在指定模型上重测。

### 2. 关系建模：区分合作意愿和能力

[Explicit Trait Inference for Multi-Agent Coordination](https://aclanthology.org/2026.acl-long.77/)，ACL 2026；[全文](https://arxiv.org/html/2604.19278)。

ETI 从互动历史维护 warmth 与 competence 两类对手特征，再用于决策。作者在经济博弈和 MultiAgentBench 中报告了相对其对照的改进。它利用可观察的稳定行为模式，不要求模型具有人的内在人格。

**对项目的用法：** 对同一损失同时保留“对方不愿合作”“对方算错了”“对方没有资源”等可竞争解释；用后续行动更新判断。当前 `hypothesis / alternative` 已有入口，但只有一个 `trust` 标量，没有区分这些维度，也没有检验猜测能否预测下一次行动。新增维度应配合消融，不能只增加面板字段。

### 3. 心理到行为：候选假设、行为预演和训练是不同成本层级

[Infusing Theory of Mind into Socially Intelligent LLM Agents](https://arxiv.org/html/2509.22887v2)，ToMA，发表于 ACL 2026 Findings。

ToMA 探索多个心理假设及其对应发言，用后续对话模拟选择有助于目标的轨迹，并以心理状态和发言共同训练小模型。论文实验使用每个情境 2 个心理假设、每个假设 2 个发言候选，并比较仅训练发言、仅训练心理状态、联合训练等条件。

**对项目的用法：** 首先将下一步预测变成有明确对象、时间范围和结果的判断，随后对照实际行为；再考虑仅在少数重要节点比较候选行动。全面加入多候选预演会进一步增加当前调用成本。论文的小模型收益包含训练作用，不能将其当成“给 Apodex 多加一段提示就能得到同等效果”的证据。

论文也明确承认心理状态没有唯一的真值，其评估使用 LLM 评审并辅以人类核验；目标完成能力与人类心理真实性应分别讨论。

### 4. 情绪调节：感受与表达分离有价值，但证据仍初步

[Feeling First, Speaking Second: A Dual-Process Cognitive-Affective Architecture for LLM Agents](https://aclanthology.org/2026.cas-1.7/)，CAS @ LREC 2026，2026-05-16；[全文](https://aclanthology.org/2026.cas-1.7.pdf)。

该工作区分即时评价 Appraisal 和策略性表达 Formulation，结合记忆、人格与目标。作者观察到策略规划可能压过情绪反应；同时明确说明实验只有 8 份对话、两个情境，属于定性概念验证，且串行认知调用引入明显延迟。其 Appraisal 阶段未纳入目标，也是作者承认的局限。

**对项目的用法：** 保留“感受”和“如何表现”的分离，检验同样受伤时，克制、重新理解或反击是否带来不同实际选择。当前状态是每次由模型生成的报告，没有已经校准的情绪惯性或调节动力学。不能把“先写心理，再作决策”的顺序本身视为已经复现人的心理因果机制，更不应照搬多层串行调用。

### 5. 信任的行为测量：核查可以有真实代价

[Trust Between AI Agents: Measuring Formation, Breakage, and Recovery, with Implications for Governing Multi-Agent Systems](https://arxiv.org/abs/2606.14923)，2026-06 预印本；[全文](https://arxiv.org/html/2606.14923)。

研究把核查队友答案设置为有资源成本的选择，并相对于同模型的无记忆条件测量核查减少。在其测试的六个模型快照中，信任形成、针对责任人的警惕、向全队扩散的警惕，以及失败后的恢复速度存在差异。作者明确限制结论于简化任务、小样本、固定策略伙伴和被测试快照。

**对项目的用法：** 可以另设有信息不确定性的验证任务，观察人物是否愿意付费核实、向谁追问、要求何种担保。当前信任博弈账本是公开且确定的，不能为了增加“核查”按钮而让人物付费查看已知事实；需要明确的私有信息和可获得的新证据。该论文测量行为上的信任，不宣称读出了内部心理表征。

[A closer look at how large language models ‘trust’ humans: patterns and biases](https://royalsocietypublishing.org/rspa/article/482/2335/20251113/481264/A-closer-look-at-how-large-language-models-trust)，Proceedings A，2026-04-08，则通过模型与人类比较发现：LLM 的信任判断可更极端、更一致、更接近文本线索的机械映射。它直接提醒我们，“信任条变化得清楚”不等于“更像人”。

### 6. 记忆：事实、经历、概括与观点应保留不同语义

[Hindsight is 20/20: Building Agent Memory that Retains, Recalls, and Reflects](https://arxiv.org/abs/2512.12818)，2025-12；[论文全文](https://arxiv.org/html/2512.12818)、[官方实现](https://github.com/vectorize-io/hindsight)、[官方文档](https://hindsight.vectorize.io/)。

论文区分 world、experience、observation、opinion 四类逻辑网络，分别处理世界信息、自身经历、实体概括和可更新观点，通过 retain、recall、reflect 管理。其主要评测是长期对话记忆任务，不能直接外推为心理博弈中的收益或心理真实性。

**对项目的用法：** 保留确定性账本作为事实源；将对手的话记录为“他说了什么”；为主观判断保存证据、形成时间和后续修订。给工作上下文设置明确预算，并按当前角色、阶段和对手提取必要证据。当前 SQLite 与事件存储可以先实现这些语义；没有必要先迁移整个数据库或安装 Hindsight 服务。论文中的记忆命名和最新 SDK 接口也需分别核对。

### 7. 输出截断：过度思考是候选解释，不能直接作为故障诊断

[ThinkBrake: Efficient Reasoning via Log-Probability Margin Guided Decoding](https://aclanthology.org/2026.findings-acl.1095.pdf)，ACL 2026 Findings；另核对了其较早的 [tool reasoning 版本](https://arxiv.org/html/2510.00546v2)。

该研究在数学、科学及工具任务中研究过度思考，以停止符与继续生成 token 的概率差决定是否终止推理。2026 版本明确要求推理分隔符和模型 logits，指出黑盒 API 可能无法提供这些能力；停止判断也不保证答案正确。

**对项目的用法：** 不在当前 Cardinalize 接入里宣称实现了 ThinkBrake。先对固定输入比较心理与行动各自的 reasoning effort、上下文长度和输出预算，并保留失败次数、首轮有效调用率及延迟。当前 5 次截断只证明输出耗尽，没有足够证据认定每一次都属于论文所定义的“已找到正确答案后继续推翻”的过度思考。增大预算、减小预算和相同参数重试都应实测。

### 8. 心理博弈还包含“谁知道什么、该问谁”

[Sotopia-ToM: Evaluating Information Management in Multi-Agent Interaction with Theory of Mind](https://arxiv.org/html/2605.02307v1)，2026-05 预印本。

其 160 个经人审核的场景包含 3–5 个 Agent、分割的私有知识、公开与私聊频道，评估信息披露、向正确对象询问、效率和隐私违规。论文报告，即使强模型也会询问不足、对象选错或输出格式失败。

**对项目的用法：** 保留公开信息与私有经历的权限隔离，逐步增加可验证的知识状态和信息目标；评价人物是否问到了关键问题、是否基于实际知道的信息作出选择。不要给博弈参与者注入研究视角看到的真实私人状态。该工作不是对经济博弈中欺骗最优性的验证。

## 建议的下一轮实验顺序

| 顺序 | 具体改动 | 验收依据 | 当前限制 |
| --- | --- | --- | --- |
| 1 | 保存脱敏的单次决策输入、可见证据、合法工具、模型参数，支持固定情境复测 | 同一输入下比较首轮有效输出率、截断率、角色/金额错误、延迟与 token | 当前主要保存事件、源码和响应计数，没有完整的最终模型请求快照 |
| 2 | 把确定性世界快照、听到的陈述、主观信念分区输入；给心理评价设置独立预算 | 检查“尚未投资却以为到账”等错误是否减少，比较固定上下文预算 | 不应自动把所有主观误判改成正确判断或补造行动 |
| 3 | 固定人物其余设定，单独操控一个人格维度；设置相同刺激的修复分支 | 比较道歉、真实补偿、无回应后的行动分布，并报告失败样本 | 当前完成局人物快照不等于任意中途世界快照；先用隔离的决策情境，真正中途分叉需新增支持 |
| 4 | 引入对手意愿/能力的独立假设，并评估下一步行为预测 | 与只有总信任值的条件比较；明确预测事件后才能计算准确率或 Brier score | 当前 `expectedNextMove` 是自由文本，`confidence` 也不是已校准的事件概率 |
| 5 | 在有效机制上再做自由对局和长局 | 人格辨识、策略连续性、实际收益、关系恢复轨迹与稳定性 | 不能挑选戏剧性样本或强制人物背叛来制造成功 |

以上是研究假设和实施次序，不是本轮新测得的效果。先做少量成对试验估计方差和故障率，再确定样本量；世界随机种子不能保证外部模型输出可重复。新的机制应分别开关，避免同时修改人格、记忆、规则和模型参数后无法归因。

## 前端应展示什么

保留现有黑白 shadcn 界面和心理回看，进一步让研究者能对照四件事：**已发生的事实、人物当时的理解、对外说法、实际选择**。对未验证的解释使用“猜测”等明确标识；情绪强度仍标记为主观模拟。后续可展示预测是否落空、信任恢复的行为证据和实验分支对比，而不只展示心理分数。

这些只是本轮基于文献的界面建议；当前实际页面仍以 `psychology-v4.md` 中的已实现能力为准。
