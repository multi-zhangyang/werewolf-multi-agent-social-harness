# 心理参与博弈：实现与探索性验收结果

2026-10-03。本版已接通结构化事实、带惯性的心理更新、正式状态驱动决策、真实资源结算、独立修复分支和研究回看。模型保持 Cardinalize 的 `apodex/apodex-1.1-mini:free`，检索资料使用 Exa。

固定情境达到登记的经验稳定性门槛，六场自由局完成五场。人格对行为的影响呈现条件依赖，尚不能宣称形成了稳定、可辨识的人格行为模式。角色、金额和时序误读仍是当前模型的主要质量限制。

## 修复条件与人格结果

实验设置为第一轮承诺返还一半、投资6、返还0。三个分支从同一个背叛后状态独立进入：无回应、相同道歉、相同道歉加真实补偿9。第二轮角色交换，观察自主返还和补偿；第三轮观察合法的再次投资。后续伙伴采用固定规则，因而这是受控情境下的结果，不代表开放社交环境。

没有出现跨条件、跨机制一致的“高宜人性更合作”。低返还也不能直接等同报复。三条受控失败全部集中于混合机制的道歉条件：高宜人性2条、低宜人性1条，完整人格对照只剩2对；缺失可能造成偏差。小样本bootstrap区间可能很窄，尤其n=2时，不应被解读为强证据。这里不作显著性结论或多重比较后的发现声明。

惯性也没有普遍提高合作：高宜人性无回应条件下，混合组相对关闭惯性的后续投资差为+2.8点[1.2, 4.4]；低宜人性补偿条件下为-1.0点[-2.6, 0.6]。其余机制差值全部保存在审计JSON中。工程上状态连续性已实现；参数是否改善研究有效性仍需更大、独立的实验检验。

预测按“人物＋目标事件”仅保留最后一次有效预测，再按分支计算平均Brier。混合机制六组均值约0.151–0.217；关闭惯性约0.129–0.222。关闭心理组没有预测，保留缺失，不补零。策略修订统计的是声明的策略类别变化，不能替代对真实报复或修复动机的判断。

## 文字质量与版本边界

固定抽取首个重复的六条混合分支，以及全部六场自由局的预定时点，包含失败和未观察到的阶段。代码助手逐条核对了角色、账本、时序和明确策略金额；尚无人类独立复核。详见[原文核查](v5-model-quality.md)。

典型问题包括把首轮“返还14、另补偿1”记成“只还1”，在实际投资之前写“已经到账”，以及期待第三轮由错误的一方投资。多数明确的返还／补偿金额计划与随后工具选择一致，但这不能证明其主观解释正确。界面明确区分主观报告、收到的说法和实际账本，原文保持原样。

受控批次固定使用`2c81923f91b9…`版本、8192输出预算，保留了等待导致未提交行动及旧截断边界下的两次400失败。后续自由局使用`59f3fd3c9b79…`：心理16000、交流和行动8192，均为low，请求超时240秒，修复不完整JSON进入SDK纠正历史的问题。两批固定确认的实际决策代码一致，源码区别仅为隔离复测helper。

当前工作区又修复了多关键词记忆检索，源码为`e5eb6cc6d64d…`。只读原失败局、在内存副本比较四个原查询，其中三个从零命中变为有授权来源的结果；没有另跑模型，也没有将旧失败改为成功。这一局部修正有离线回归验证，六场完成率仍属于修正前冻结的检索版本。原受控批次没有调用`remember`或`recall_memory`，不会受这项检索修正影响。

更早诊断批次和停止记录全部保留，未并入上述成功率。它们及完整实现细节见[机制与验证历史](psychology-v5.md)。
