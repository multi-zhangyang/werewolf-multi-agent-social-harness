# 场景与成熟度验收

一个场景只需要实现 `SocialWorld` 契约，不需要复制 Agent、SSE 或 UI 代码。

每个世界应明确四件事：

1. 参与者在每个阶段能看到什么；
2. 哪些 SDK 工具可以改变世界；
3. 顺序行动和同时行动如何调度；
4. 工具提交后如何确定性结算并生成下一轮经历。

现有场景覆盖五类人性博弈：

| 场景 | 核心冲突 | 可观察内容 |
| --- | --- | --- |
| 狼人杀 | 隐藏身份与多方欺骗 | 发言、私聊、投票、夜间行动、胜负 |
| 阿瓦隆 | 忠奸难辨与暗中破坏 | 组队、公开表决、秘密任务票、最终刺杀 |
| 囚徒困境 | 短期背叛与长期互惠 | 谈判、承诺、同时选择、分数 |
| 蜈蚣博弈 | 传递信任与随时摘果 | 奖池翻倍、轮流抉择、不对称分成 |
| 胆小鬼博弈 | 虚张声势与两败俱伤 | 对峙谈判、同时闪避或硬冲 |
| 猎鹿博弈 | 合作高回报与确定性 | 结伴承诺、同时出发、背叛代价 |
| 公共品博弈 | 公共收益与搭便车 | 群体协商、投入、结算、关系变化 |
| 信任博弈 | 交出控制权后的返还 | 投资、返还、角色交换、记忆 |
| 最后通牒博弈 | 分配权与公平惩罚 | 提议、拒绝、轮换、关系记忆 |
| 选美博弈 | 高阶信念与群体误判 | 讨论、同时选择、目标结算 |
| 密封拍卖 | 私密估值与策略误导 | 讨论、密封出价、次价结算 |
| 谈判博弈 | 同时叫价与私密保底 | 报价、承诺、成交或跌回保底、关系变化 |
| 吹牛骰 | 递进叫价与开盅对赌 | 叫点、质疑、开盅结算、虚张声势 |

新增场景时，让每一个可观察行为都通过事件流进入 UI；不要只返回一个最终分数。
适合继续加入的方向包括联盟谈判、谣言与信息级联、身份交换、不对称承诺或
多轮声誉博弈。

- ✅ **已验证**：该机制存在，且有专属离线测试或真实对局证据；
