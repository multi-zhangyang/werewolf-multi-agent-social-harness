# 场景规则

新建入口提供以下四个场景；历史归档继续按原样只读展示。

## 信任博弈

2 人，2–16 轮。投资者每轮持有 10 点，投资整数 0–10；投资乘 3 交给受托者，受托者从到账额中返还任意整数。投资者所得为 10−投资+返还，受托者所得为 3×投资−返还。每轮交换角色。投资前、投资到账后及结算后均有有界交流机会。

`trustProtocol=classic` 保留经典规则。界面默认选择 `pledge-repair`：投资前受托者通过 `pledge_return` 自主选择承诺返还到账的 0–100%；最低承诺额向下取整。承诺可以违反，世界根据真实返还生成履约结果，不生成心理判断。结算和交流后，受托者可用 `repair_transfer` 从自己累计所得中转出 0 到现有整数余额作为补偿，随后再交流并交换角色。补偿不会改变原先是否违约的记录。零投资下的零返还不构成金额违约，选择零补偿同样是合法行动。

## 公共品博弈

3–8 人，2–16 轮。每人每轮 10 点，密封提交整数 0–10。所有人提交后共同池乘 1.6，再均分。每人所得为 10−个人投入+公共池×1.6/人数。未揭晓前，其他人不能查看贡献额。结算后可继续交流。

## 信息交易

2 人，2–16 轮，角色在本局固定。发送者在每轮报告前知道真实质量；高、低质量各有 50% 机会，世界种子决定序列。发送者提交高或低质量报告，双方交流后接收者接受或拒绝，随后公开真值、报告是否一致和所得，并留出复盘交流。报告不改变真值；拒绝也会公开核验。

`signalingIncentives=conflicting` 为界面默认：接受高质量双方各得 6 点，接受低质量发送者得 6 点、接收者得 0 点，拒绝双方各得 2 点。`aligned` 仅将接受低质量时发送者的所得改为 0 点，因此双方利益一致。两种条件的质量序列、动作与 Agent 相同，允许自行决定怎样报告和回应。

原生动作是 `declare_quality({highQuality: boolean})` 和 `choose_offer({accept: boolean})`。当前真值在结算前仅进入发送者观察，不进入接收者输入或公开状态；历史真值在核验后可作为下一轮判断的证据。报告不一致与主观欺骗意图分别记录，不能混为同一指标。

## 狼人杀

6–12 人，2–8 天。沿用 `src/society/scenarios/werewolf/roles.ts` 的逐人数牌组，使用世界种子洗牌。

- 第一天有上警、竞选交流、退选、密封选举；竞选者含退选者不参与警长票。警长的白天放逐票重 1.5。无人上警或全员上警时无警长。平票候选人交流后再次选举，再平票则空缺。
- 白天交流后密封放逐。第一次平票最多两人陈词后重投，平票者不投票；再次平票无人出局。
- 出局公开身份；被投者有一次可选择沉默的遗言机会，小丑除外。警长死亡先移交或撕毁警徽。猎人可开枪，毒杀不能开枪；狼王在投票或枪杀出局时可开枪。连锁行动完成后立即判断胜负。
- 狼队夜间交流和提名；提名平票提供一次重新交流和提名，仍平票按稳定 ID 顺序结算。
- 预言家查验他人，隐狼显示为村民；通灵师读取死者真实身份。查验结果仅本人可见。
- 女巫解药、毒药各一次，每晚最多用一瓶，不能自救。解药可用时知道狼刀目标。
- 守卫不能连续两晚守同一人，能自守，不抵挡毒药；同守同救仍死亡。
- 白痴首次被投时免死并失去票权，再次被投时出局。骑士有一次白天决斗：狼目标死，否则骑士死。
- 梦魇可封禁目标下一次日票，狼美人被放逐时带走当晚魅惑对象；白狼王被放逐时带走所有投给他的玩家。这些行为与当前项目已有规则一致。
- 小丑被投出单独获胜后离场，主局继续。狼队全灭则村庄胜；狼队达到人数优势或村庄超过期限未消灭狼人则狼队胜。

所有行动的身份、存活、阶段、目标和重复提交限制在场景层验证，不依赖模型遵守文字描述。
