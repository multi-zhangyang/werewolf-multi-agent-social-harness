# 场景扩展

一个场景只需要实现 `SocialWorld` 契约，不需要复制 Agent、SSE 或 UI 代码。

每个世界应明确四件事：

1. 参与者在每个阶段能看到什么；
2. 哪些 SDK 工具可以改变世界；
3. 顺序行动和同时行动如何调度；
4. 工具提交后如何确定性结算并生成下一轮经历。

现有场景覆盖四类人性博弈：

| 场景 | 核心冲突 | 可观察内容 |
| --- | --- | --- |
| 囚徒困境 | 短期背叛与长期互惠 | 谈判、承诺、同时选择、分数 |
| 公共品博弈 | 公共收益与搭便车 | 群体协商、投入、结算、关系变化 |
| 信任博弈 | 交出控制权后的返还 | 投资、返还、角色交换、记忆 |
| 狼人杀 | 隐藏身份与多方欺骗 | 发言、私聊、投票、夜间行动、胜负 |

适合继续加入的方向包括密封拍卖、联盟谈判、谣言与信息级联、身份交换、
不对称承诺或多轮声誉博弈。新增场景时，让每一个可观察行为都通过事件流
进入 UI；不要只返回一个最终分数。
